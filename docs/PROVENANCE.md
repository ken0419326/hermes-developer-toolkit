# Provenance and scope of authorship

## Upstream capabilities

[Hermes Agent](https://github.com/NousResearch/hermes-agent) provides the agent CLI, model-provider integration, skill discovery, slash-command handling, and terminal tool calling. This repository does not claim authorship of Hermes or of any model provider.

The original university assignment supplied a starter repository with a development runner, output conventions, task skeletons, reference opponents, and private course evaluation infrastructure. Those course datasets, gold answers, reference opponents, grader code, and private feedback are not redistributed here.

## Portfolio implementation

Ken Shen created this standalone portfolio edition from his course project. The included work consists of:

- the four rewritten skill specifications;
- a shared task/result contract and atomic output layer;
- SQL compilation checks;
- Python syntax, entry-function, import, sample, and timeout validation;
- the deterministic static reviewer and its documented rule boundaries;
- the Hermes subprocess boundary;
- original public examples, fixture outputs, offline tests, CI, and documentation.

The fixture candidates are authored examples, not captured model outputs and not evidence of model quality.
